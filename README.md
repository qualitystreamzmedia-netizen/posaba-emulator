# Dissolvers Emulator

A portable Android emulator bundle preloaded with the Dissolvers IPTV player.

## Install

Download **Install Dissolvers.exe** (see Releases, or the distribution folder) and run it.
It downloads the bundle from the `v1` release and sets it up. The first launch of the
emulator itself takes about two minutes while it installs the bundled apps.

The full bundle (~1.9 GB) is attached to the [v1 release](../../releases/tag/v1).
